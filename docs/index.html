🔑 الدخول

أدخل مفتاح GitHub (Token) مرة واحدة، ويُحفظ في هذا المتصفح فقط.

كيف أحصل على المفتاح؟
  1. افتح github.com/settings/personal-access-tokens/new
  2. اكتب اسماً مثل zinou-admin، واختر مدة الصلاحية (مثلاً سنة).
  3. في Repository access اختر Only select repositories ثم zinou-store.
  4. في Permissions اختر Contents ← Read and write.
  5. اضغط Generate token، انسخه والصقه هنا.
